# یادداشت انتشار PW Agent v1.4.0-alpha.3

**وضعیت: نسخه آزمایشی و GitHub Latest؛ نه Stable و نه تأییدشده برای نصب روی تمام روترها.**

## موارد اجراشده
- نصب اولیه و Provision مجدد به شش دستور کوتاه با دکمه کپی مجزا تبدیل شده؛ توکن نصب به URL منتقل نمی‌شود و اعتبار آن ۳۰ دقیقه و یک‌بارمصرف است.
- برای تغییر SSID یک UCI Section مشخص، بکاپ روی خود روتر ذخیره می‌شود، Watchdog مستقل ۹۰ثانیه‌ای راه می‌افتد و در صورت تأییدنشدن تغییر، روتر تنظیمات قبلی را برمی‌گرداند. با شروع مجدد سرویس/روتر هم بازیابی اجرا می‌شود.
- اکشن‌های محدود و صریح ری‌استارت سرویس‌های dnsmasq / odhcpd / sysntpd با RBAC و تأیید کاربر.
- فرم ایجاد و مدیریت هشدارها و زمان‌بندی‌های دوره‌ای در پنل جدید؛ نمودارهای اصلی با بازخوانی محدود ۲۰ثانیه‌ای.
- گزارش پکیج‌ها روی apk و opkg و رفع Allowlist دستورهای read-only.
- تست سریع CI برای Go/PHP/JS/Shell در کنار ساخت امضاشده چندمعماری.

## هنوز پیاده‌سازی کامل نشده
- اعمال Rule واقعی OpenVPN با Policy Routing، Kill Switch، DNS/IPv6 leak protection و import امن کلیدها.
- Block/Rate limit واقعی کلاینت‌ها، تنظیم SQM/QoS، تغییرات کامل Wi-Fi و Firewall و WAN با watchdog.
- RGB و LED زمان‌بندی‌شده روی سخت‌افزارهای مختلف، قابلیت‌های اختصاصی مودم‌ها، تست سخت‌افزاری روی تمامی مدل‌ها و آپدیت خودکار و بازگشت Backend سی‌پنل.

**نکته مهم:** متن UI نباید اجرای این موارد ناتمام را به کاربر وعده دهد. روی روتر اصلی بدون دسترسی بازیابی مستقل، Safe Apply را آزمایش نکن.

## ارتقای نسخه
از فایل‌های امضاشده نسخه دقیق استفاده کن. از `config.php` و MySQL بکاپ بگیر، دوباره `setup.php` را اجرا نکن و Backend و Agent را هماهنگ ارتقا بده. برای Provision مجدد توکن جدید صادر کن. هر خط دستور نصب را جداگانه Paste کن.
