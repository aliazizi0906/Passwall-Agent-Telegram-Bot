# انتشار PW Agent v1.4.0-alpha.5 — مرکز ماژول‌های LuCI و بازطراحی پنل

**وضعیت: Alpha آزمایشی؛ نه نسخه پایدار و نه کپی کامل تمام صفحات/افزونه‌های LuCI.**

## تغییرات

- مرکز LuCI با ۲۹ ماژول در حوزه وضعیت، سیستم، شبکه، Wi-Fi، سرویس‌ها و VPN؛ فهرست براساس وجود فایل تنظیمات UCI روی روتر و تفکیک «قابل اجرا»، «فقط مشاهده»، «پکیج موجود نیست» و «Adapter لازم دارد». جست‌وجو و فیلتر وضعیت دارد.
- تغییر واقعی نام روتر در UCI با بکاپ محلی و تأیید ۱۲۰ثانیه‌ای.
- فهرست رزروهای DHCP و افزودن/حذف امن رزرو IP ثابت براساس MAC در Subnet شبکه LAN؛ رزروهای سایر برنامه‌ها قابل حذف نیستند.
- فعال/غیرفعال‌کردن Wi-Fi Interface مشخص با Rollback زمان‌دار و تأیید تغییر.
- صفحه ترمینال SSH از ابتدا بازطراحی شد: چیدمان واکنش‌گرا، اندازه صحیح آیکون‌ها، وضعیت اتصال، خروجی LTR، پاک‌سازی خروجی، و اتصال به همان روتر انتخابی در داشبورد.
- صفحه OpenVPN با فرم‌های منظم دو‌ستونه در دسکتاپ و تک‌ستونه در موبایل، آیکون‌های SVG با ابعاد ثابت، و تفکیک Dry Run از اعمال واقعی PBR اصلاح شد.
- آیکون‌های نوار ابزار، استایل مشترک فرم‌ها، نمایش فارسی/انگلیسی، فوکوس کیبورد و محدودیت عرض کارت‌ها بهینه شدند.
- تست Go/PHP/JS و بررسی ساختاری CSS و ترمینال به CI اضافه شد.

## محدودیت‌ها

«تمام امکانات LuCI» بسته به نسخه OpenWrt، پکیج‌های نصب‌شده، افزونه‌های ثالث و سخت‌افزار فرق می‌کند. پیکربندی کامل VLAN، Bridge، Firewall Zones، کلیدهای WAN، شبکه مهمان، دیسک، DDNS، UPnP، AdBlock، Cron دلخواه و بسیاری از افزونه‌های `luci-app-*` در این نسخه پیاده‌سازی نشده‌اند. پنل این موارد را به‌عنوان قابلیت عملیاتی معرفی نمی‌کند. برای اکشن‌های شبکه همچنان مسیر بازیابی مستقل لازم است.

انتشار روی GitHub باعث بروزرسانی خودکار سی‌پنل یا روتر Gale نمی‌شود. برای نصب، بسته‌های امضاشده Backend و Agent هم‌نسخه را استفاده کن؛ قبل از ارتقا بکاپ بگیر و Setup اولیه را دوباره اجرا نکن.
