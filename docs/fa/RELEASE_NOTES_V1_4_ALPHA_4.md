# PW Agent v1.4.0-alpha.4 — کنترل‌های اجرایی پیشرفته

**وضعیت: Alpha آزمایشی؛ GitHub Latest، ولی نه Stable و نه تأییدشده روی تمام روترها.**

## قابلیت‌های عملیاتی اضافه‌شده

- **PBR:** ایجاد و حذف Policyهای دارای پیشوند `pw_` بر اساس مقصد CIDR و یک Interface واقعی موجود در تنظیمات network؛ به بسته نصب‌شده `pbr` نیاز دارد و با Rollback محلی اجرا می‌شود.
- **OpenVPN:** فعال و غیرفعال‌کردن پروفایل‌های موجود UCI با Rollback. ساخت رمز یا بارگذاری فایل محرمانه هنوز فعال نیست.
- **کلاینت‌ها:** مسدودسازی یا رفع مسدودی ترافیک مستقیم از zone `lan` به `wan` بر اساس MAC. محدودیت نرخ اختصاصی دستگاه و VLANهای دیگر پوشش داده نمی‌شوند.
- **SQM:** اعمال سرعت دانلود/آپلود روی Queue موجود، نه محدودیت پهنای باند هر کلاینت.
- **Wi‑Fi:** اعمال امن کانال Radio با مهلت ۱۲۰ ثانیه؛ تغییر SSID همچنان Rollback نودثانیه‌ای دارد.
- **Firewall:** Rule مسدودسازی مستقیم LAN→WAN و Rule مستقل جلوگیری از DNS کلاسیک TCP/UDP پورت ۵۳، هر دو با امکان بازگشت.
- **LED:** کنترل رنگ روی LEDهای RGB استاندارد Linux sysfs با `multi_intensity` و Trigger غیرفعال؛ نه سخت‌افزار اختصاصی یا همه روترها.
- **Backend:** ابزار CLI برای ارتقای فایل‌های سی‌پنل با امضای Ed25519، بررسی SHA256، بکاپ و بازگشت. اجرای خودکار از صفحه وب هنوز غیرفعال است.

**بخش‌هایی که هنوز کامل نشده‌اند:** Kill Switch با تضمین عدم نشت IPv6/DoH/DoT، محدودیت سرعت و اولویت‌بندی هر دستگاه، ساخت شبکه مهمان و تنظیم امن رمز Wi‑Fi، Cell Lock/SMS وابسته به مودم، زمان‌بندی LED، آپدیت یک‌کلیکی Backend و تست واقعی قطع برق روی دستگاه.

## نکات ارتقا

Backend و Agent باید هم‌نسخه باشند. روی سی‌پنل نصب‌شده `setup.php` را دوباره اجرا نکن و `config.php` را جایگزین نکن. از دیتابیس و فایل‌ها بکاپ بگیر و ارتقا را ابتدا روی هاست آزمایشی انجام بده. Ruleهای شبکه را تا پیش از آزمون روی روتر واقعی بدون مسیر دسترسی فیزیکی فعال نکن.

تأیید تغییرات UCI باید پیش از مهلت ۱۲۰ ثانیه انجام شود؛ اگر تأیید نشود روتر تلاش می‌کند فایل UCI قبل را بازیابی کند.
