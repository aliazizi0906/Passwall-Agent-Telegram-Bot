# وضعیت اجرایی PW Control Center — شاخه v1.3

> **نسخه v1.3.0-rc.2 به‌صورت Pre-release عمومی منتشر شده، اما نسخه پایدار v1.3.0 نیست.** کد و بسته‌های قابل دانلود در GitHub موجودند؛ نصب‌های v0.6 تا زمانی که آگاهانه و با روش ارتقا به‌روزرسانی نشوند، تغییر نمی‌کنند.

## انجام‌شده و قابل تست در محیط آزمایش
- داشبورد وب مستقل زیر `server/control/index.php`؛ فارسی/انگلیسی، راست‌چین/چپ‌چین، دارک/لایت.
- استفاده از احراز هویت **Telegram Mini App initData**، RBAC، Device Scope و Command Queue فعلی. این پنل در Browser مستقل فعلاً ورود ندارد.
- Fleet Picker، Metrics و وضعیت WAN/DNS/Passwall2، نمودار داده واقعی، وضعیت CPU/RAM/Latency، تاریخچه فرمان.
- نمایش واقعی اطلاعات DHCP/ARP برای دستگاه‌های شبکه و وضعیت Wi-Fi؛ هیچ رمز Wi-Fi موجودی نمایش داده نمی‌شود.
- خواندن وضعیت DNS/Route، Network Doctor و قابلیت‌های کشف‌شده از Agent.
- مدیریت مجاز Passwall2: لیست و تست نود، انتخاب نود، افزودن لینک، اشتراک‌ها و Shunt read-only.
- اعتبارسنجی و تأیید عملیات حساس Passwall2 سمت PHP؛ Queue encryption برای لینک و URL اشتراک از کد v0.6 استفاده می‌کند.
- پنل محلی **LuCI → Services → PW Control Center** برای وضعیت روتر، Clientها، Wi-Fi، Doctor، سخت‌افزار و LED؛ فرمان‌های CLI آن فقط خواندنی و محدود به rpcd ACL هستند.
- تشخیص پکیج GoogleWifiLED و خواندن وضعیت LED در صورت نصب؛ کنترل RGB هنوز در دست توسعه است.
- CI شامل Build شش معماری Go، Go Test/Vet/Format، PHP lint، JavaScript lint، تست اعتبارسنجی داده‌ها، تست Setup و Shell/JSON.

## هنوز پیاده‌سازی یا تأیید نشده (باید پیش از GA کامل شود)
- کنترل عملیاتی Clientها: Block، سرعت‌گذاری، زمان‌بندی، کنترل والدین و QoS.
- حالت امن Apply و Rollback زمان‌دار برای WAN/Wi-Fi/DNS/Firewall.
- Kill Switch، DNS split، عدم نشت IPv6/DNS و تفکیک ایران همراه با تست واقعی مسیر ترافیک.
- داشبورد تنظیمات سلولی 4G/5G، دکل و باند و پیامک/USSD فقط روی مودم‌های دارای Adapter واقعی.
- کنترل RGB و خاموشی شبانه با GoogleWifiLED، همراه با تست Google Wifi واقعی.
- پیاده‌سازی Native WireGuard/OpenVPN، SQM/UPnP، Bufferbloat و Internet speed-test از روتر.
- مرورگر مستقل با Session امن، CSRF و مدیریت نشست.
- انتشار بک‌اند v1.3 با Migration نسخه‌دار، Signed Release، Rollback و اجرای تست Upgrade از v0.6.
- تست عملی روی OpenWrt 24/25 و سخت‌افزار واقعی (armv7, arm64 و مودم‌های سلولی).

## راهنمای تست بدون دستکاری نصب اصلی
1. فایل‌های شاخه توسعه را فقط روی محیط **Staging** قرار دهید. `config.php` و Database تولید را کپی نکنید مگر با روش بکاپ رمزنگاری‌شده و دسترسی محدود.
2. برای Remote Preview مسیر `/control/` را **از داخل Mini App مجاز تلگرام** باز کنید؛ باز کردن مستقیم آدرس در مرورگر به معنای ورود نیست.
3. بخش‌های جدید Agent مثل `agent.capabilities` و `network.doctor` تنها پس از نصب **باینری توسعه سازگار** پاسخ می‌دهند؛ Agent v0.6.0 قدیمی آن‌ها را نمی‌شناسد.
4. برای تست محلی، Firmware/Agent توسعه به همراه فایل LuCI و ACL باید روی روتر آزمایش نصب شود.
5. عملیات تغییردهنده را ابتدا با یک روتر غیراصلی آزمایش کنید.

## مرز انتشار
موفقیت CI به معنای سلامت Syntax/Build و تست‌های موجود است، نه تضمین عملکرد تمام ماژول‌ها روی سخت‌افزار یا امنیت یک Release عمومی. تا انجام موارد بالا، برچسب نهایی `v1.3.0` و انتشار رسمی انجام نمی‌شود.
