# PW Agent v1.4.0-alpha.1 — GitHub Latest (Alpha, **not Stable**)

This release is published as the repository's **Latest** download by explicit maintainer request. Its **Alpha** version name is intentional: it is **not production-certified**, and does **not** claim feature parity across all OpenWrt hardware.

## Included

- Standalone browser login configured during first cPanel Setup, protected sessions, CSRF and credential rotation.
- Redesigned bilingual RTL/LTR web control center and login; responsive mobile navigation and dark/light themes.
- Vazirmatn font pinned from CDN with a verified bundled WOFF2 fallback for offline or CDN-failed deployments.
- Signed OpenWrt packages for 13 CPU targets and cPanel backend ZIP. Initial router bootstrap checks SHA256 and Ed25519 signatures.
- Read-only capability-aware OpenWrt device discovery, Wi-Fi, DNS, sysfs LEDs, cellular diagnostics, SQM, UPnP, VPN tooling and multi-router fleet.
- Owner-approved staged rollout with canary and explicit per-wave approval, migration ledger, security/validation tests and best-effort installer rollback.

## Important limits / هشدار فارسی

**For staging or noncritical test routers only.** Do not replace a live router or cPanel installation without verified encrypted DB/config backups and a separate tested recovery method.

این نسخه با وجود عنوان Latest همچنان آزمایشی است و برای روتر اصلی یا زیرساخت عملیاتی بدون پشتیبان و روش بازگشت آزمایش‌شده توصیه نمی‌شود.

- **Not implemented / not certified:** complete Wi-Fi/WAN/firewall safe-apply with reboot/power-loss rollback, actual DNS/IPv6 leak prevention and VPN kill switch, per-client shaping/blocking, full RGB control, vendor-specific cellular features, native VPN adapters, all-router compatibility or tested backend rollback.
- Hardware capabilities are detected individually; unsupported features stay unavailable or read-only.
- The built-in login's production deployment and diverse physical-router acceptance still require real-world validation.
- This release does not silently modify existing installations. Firmware/Agent upgrades remain opt-in.

## Install and verification

1. Download the cPanel ZIP from **this exact release**, and verify the SHA256 and Ed25519 signature before deployment.
2. Install to isolated **staging** PHP/MySQL hosting; configure a separate bot and database, and set the independent web username/password during `setup.php`.
3. For a test router, use the version-pinned provisioning command generated by Setup. The router needs supported OpenWrt architecture and the OpenSSL verification CLI.
4. Open `/auth/login.php` for browser access and `/control/` for the control panel.
5. Follow [the v1.4 workstream matrix](https://github.com/aliazizi0906/Passwall-Agent-Telegram-Bot/blob/feature/v1.4-secure-browser-control/docs/en/V1_4_EXECUTION.md) to distinguish implemented controls from planned ones.

The **Latest** badge means only that this is the current public download, **not** that the 14 workstreams or production certification are complete.
