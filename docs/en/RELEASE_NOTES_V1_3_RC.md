# PW Agent v1.3.0-rc.2 — Release Candidate

> **PRE-RELEASE / نسخه آزمایشی** — Do not deploy to a critical production router. This is **not** a feature-complete WRTPro replacement or a stable v1.3.0 release.

[فارسی: release notes](../fa/RELEASE_NOTES_V1_3_RC.md) · [Install](INSTALL_V1_3.md) · [Upgrade](UPGRADE_V1_3.md)

## What's new / تغییرات اصلی

- **PW Control Center**: bilingual Persian/English RTL/LTR, light/dark Telegram Mini App preview with real fleet/monitoring data.
- **Local LuCI Control Center**: offline, read-only router status, LAN devices, Wi-Fi, Network Doctor, capabilities and optional GoogleWifiLED status.
- **Passwall2**: view/test/select nodes, import links, manage subscriptions and inspect Shunt/Failover from authenticated web UI.
- **New Agent diagnostics**: `agent.capabilities`, `network.doctor`, `led.status` and corresponding CLI JSON modes for LuCI.
- **Installer and packaging**: version-pinned OpenWrt assets for six architectures, clean cPanel ZIP, SHA256 manifests, Ed25519 release signatures, safer Agent update rollback.
- **Testing**: PHP/Go/JavaScript lint and unit tests, 6-architecture cross-compilation, action parameter validation and clean cPanel ZIP creation.

## Not included yet / قابلیت‌های هنوز تکمیل‌نشده

Production-grade per-client traffic shaping/blocking/scheduling, automatic rollback for WAN/Wi-Fi/firewall changes, leak-proof IPv6/DNS kill-switch and Iran split-routing, cellular LTE/5G band/cell lock plus SMS/USSD, RGB LED color writes, SQM/UPnP advanced QoS, verified OpenVPN/WireGuard adapters and independent browser sign-in.

**Hardware-specific capabilities only appear when detected.** Cross-compilation and syntax CI tests do **not** prove behavior on physical Google Wifi or cellular modems.

## Installation / نصب

Download the **matching version** assets:
- `pw-agent-cpanel-v1.3.0-rc.2.zip` + SHA256 + signature;
- `pw-agent-openwrt-{armv7,arm64,amd64,386,mips,mipsle}.tar.gz` with SHA256/signature;
- See [فارسی: نصب](https://github.com/aliazizi0906/Passwall-Agent-Telegram-Bot/blob/v1.3.0-rc.2/docs/fa/INSTALL_V1_3.md) and [English install](https://github.com/aliazizi0906/Passwall-Agent-Telegram-Bot/blob/v1.3.0-rc.2/docs/en/INSTALL_V1_3.md).

Use a fresh **staging** cPanel directory, MySQL database, Telegram Bot and noncritical OpenWrt router. Open Setup in the extracted Backend folder, configure cPanel Cron Once Per Minute and run the one-time Provisioning command generated by Setup. Preview the new UI via the authorized Telegram Mini App and local LuCI.

**Do not delete existing `config.php`, overwrite your production database, reuse your production Bot for staging or paste tokens into tickets.** Existing v0.6 deployments should follow the [migration guide](https://github.com/aliazizi0906/Passwall-Agent-Telegram-Bot/blob/v1.3.0-rc.2/docs/fa/UPGRADE_V1_3.md).

## Security and compatibility

- Self-hosted PHP/MySQL backend on cPanel; outbound HTTPS HMAC router communication.
- Signed OpenWrt update artifacts and device-scoped RBAC. Installer bootstrap currently checks SHA256 downloaded over HTTPS; independent Ed25519 bootstrap verification on bare OpenWrt has not been implemented, so assess your supply-chain requirements before deployment.
- One-time provisioning tokens expire after 30 minutes.
- Native local LuCI controls in this RC are **read-only**.

See [the implementation matrix](https://github.com/aliazizi0906/Passwall-Agent-Telegram-Bot/blob/v1.3.0-rc.2/docs/en/CONTROL_CENTER_PROGRESS.md) for exact progress and release blockers.
